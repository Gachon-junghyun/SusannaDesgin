# 이미지 넣는 곳

이 폴더에 **아래 파일명 그대로** 넣으면 사이트의 플레이스홀더가 자동으로 실제 사진으로 바뀝니다.
코드는 건드릴 필요 없습니다. (파일이 없으면 크기가 적힌 회색 박스가 대신 표시됩니다.)

> 회사소개서 PDF 안에 이미 쓸 만한 실적 사진이 많이 들어 있습니다.
> 원본 사진 파일이 있으면 그걸 쓰는 게 가장 깨끗하고, 없으면 PDF에서 추출해도 됩니다.

## 촬영·선별 팁

- **야간 점등샷이 주간샷보다 압도적으로 잘 팔립니다.** 같은 현장의 주간/야간 페어가 있으면 가장 좋습니다.
- 사인만 클로즈업하지 말고 **건물 전체가 보이게** 찍으면 규모가 전달됩니다. 대형 현장이 강점인 만큼 이게 중요합니다.
- 사진은 넣기 전에 가로 폭 1920px 이하로 리사이즈하세요. WebP 변환과 반응형 처리는 Next.js가 알아서 합니다.
- 파일명은 소문자·하이픈만. 한글 파일명은 배포 환경에서 깨질 수 있습니다.

## 로고 (이미 적용됨)

회사소개서에서 추출해 **벡터(SVG)로 변환**했습니다. 별도 작업 불필요합니다.

- `public/logo.svg` — 청록 (헤더용)
- `public/logo-white.svg` — 흰색 (푸터·다크 배경용)
- `app/icon.png` · `app/apple-icon.png` — 파비콘 (S 심볼)

원본 AI/EPS 파일이 있으면 그걸로 교체하는 게 가장 정확합니다. 자세한 내용은 프로젝트 README 참고.
