# Supabase 연결하기 — 사진 직접 올리기

> 이걸 끝내면 `/admin` 에서 첫 화면 사진과 시공사례를 **코드 수정 없이** 직접 바꿀 수 있습니다.
> 15분쯤 걸립니다. 막히면 각 단계 아래의 "안 될 때" 를 보세요.
>
> **지금 안 해도 됩니다.** 연결 전에도 홈페이지는 정상 동작하고, `public/images/` 에
> 파일명 맞춰 넣는 기존 방식도 그대로 씁니다.

---

## 준비물

이메일 계정 하나. 카드 등록 필요 없습니다(무료 플랜으로 충분합니다).

---

## 1단계 — 프로젝트 만들기 (5분)

1. [supabase.com](https://supabase.com) → **Start your project** → GitHub 또는 이메일로 가입
2. **New project** 클릭
3. 입력값:

   | 항목 | 값 |
   |---|---|
   | Name | `susanna-design` (아무거나 괜찮습니다) |
   | Database Password | **자동 생성 버튼을 누르고 어딘가 저장해 두세요** |
   | Region | **Northeast Asia (Seoul)** ← 꼭 서울로 |

4. **Create new project** → 2분쯤 기다립니다

> **Region 이 왜 중요한가**: 서버가 멀수록 관리 화면의 저장·업로드가 그만큼 느려집니다.
> 나중에 못 바꾸니 지금 서울로 고르세요.

> **Database Password 는 이 작업에 쓰지 않습니다.** DB 에 직접 붙을 때만 필요합니다.
> 그래도 잃어버리면 재설정이 번거로우니 저장해 두세요.

---

## 2단계 — 테이블 만들기 (2분)

1. 왼쪽 메뉴에서 **SQL Editor** (종이에 `>_` 아이콘)
2. **New query**
3. 프로젝트의 [`supabase/migrations/0001_init.sql`](../supabase/migrations/0001_init.sql) 파일을
   열어 **전체 복사** → 붙여넣기
4. 오른쪽 아래 **Run** (또는 `Ctrl+Enter`)
5. `Success. No rows returned` 가 나오면 성공입니다

이 한 번으로 만들어지는 것:

- 테이블 3개 (`hero_slides`, `works`, `profiles`)
- 권한 정책 — 방문자는 읽기만, 관리자만 수정
- 사진 보관함 (`media` 버킷)
- **지금 사이트에 있는 슬라이드 3개 + 시공사례 15건이 그대로 들어감**

> 여러 번 실행해도 안전합니다. 중복으로 쌓이지 않게 만들어 뒀습니다.

**안 될 때**
- 빨간 에러가 뜨면 → 파일 일부만 복사된 경우가 대부분입니다. 맨 위 `-- ===` 줄부터
  맨 아래까지 전체가 들어갔는지 확인하세요.

---

## 3단계 — 열쇠 두 개 복사 (2분)

1. 왼쪽 아래 **톱니바퀴(Project Settings)** → **API**
2. 두 값을 복사합니다:

   | 화면의 이름 | 넣을 곳 |
   |---|---|
   | **Project URL** | `NEXT_PUBLIC_SUPABASE_URL` |
   | **anon** `public` | `NEXT_PUBLIC_SUPABASE_ANON_KEY` |

3. 프로젝트 폴더의 **`.env.local`** 파일을 열어 `=` 뒤에 붙여넣습니다:

```
NEXT_PUBLIC_SUPABASE_URL=https://abcdefghijk.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3M...
```

> **`service_role` 키는 절대 복사하지 마세요.** 바로 아래 있어서 헷갈리기 쉽습니다.
> 그 키는 모든 권한 검사를 무시해서, 노출되면 누구나 데이터를 지울 수 있습니다.
> `anon` `public` 이라고 적힌 것만 씁니다.

4. 제대로 됐는지 확인:

```bash
npm run supabase:check
```

전부 초록색 ✔ 이면 성공입니다. ✘ 가 있으면 아래에 뭘 해야 하는지 한국어로 나옵니다.

권한이 제대로 걸렸는지도 확인할 수 있습니다 (남이 내 데이터를 못 고치는지 실제로 시험):

```bash
npm run supabase:rls
```

## 4단계 — 관리자 계정 만들기 (2분)

1. 왼쪽 메뉴 **Authentication** → **Users** → **Add user** → **Create new user**
2. 이메일과 비밀번호를 정해 입력
   (실제로 받을 수 있는 이메일이 아니어도 됩니다. **Auto Confirm User** 를 켜세요.)
3. **Create user**

> **가장 먼저 만든 계정이 자동으로 관리자가 됩니다.** 두 번째부터는 권한 없는
> 계정으로 만들어집니다.
>
> ⚠️ **2단계(SQL 실행)보다 계정을 먼저 만들었다면** 권한이 자동으로 붙지 않습니다.
> 권한을 주는 장치가 SQL 실행 시점에 만들어지기 때문입니다.
> 그럴 땐 [`supabase/make-admin.sql`](../supabase/make-admin.sql) 을 SQL Editor 에
> 붙여넣고 실행하면 해결됩니다.

### 계정 만든 직후 — 회원가입 잠그기 ★

**Authentication** → **Sign In / Providers** → **Email** →
**Allow new users to sign up** 을 **끕니다**.

이걸 안 하면 사이트 주소를 아는 사람이 임의로 계정을 만들 수 있습니다.
(권한은 없지만 계정이 쌓이는 건 막는 게 맞습니다.)

---

## 5단계 — 서버 다시 시작하고 들어가기

`.env.local` 은 서버가 시작할 때 한 번만 읽습니다. **반드시 껐다 켜야** 반영됩니다.

```bash
npm run dev
```

브라우저에서 **http://localhost:3000/admin** → 4단계에서 만든 이메일·비밀번호로 로그인.

---

## 사진 올리기

1. `/admin` → **첫 화면 사진** 또는 **주요 실적**
2. 항목의 **▸ 내용 수정하기** 를 펼치거나, 맨 아래 **+ 새 슬라이드 추가**
3. **파일 선택** → 사진 고르기 → 자동 업로드
4. **저장**

저장하는 순간 공개 홈페이지에 반영됩니다. 배포할 필요 없습니다.

| 어디에 쓰는 사진 | 권장 크기 | 비고 |
|---|---|---|
| 첫 화면 | 1920×1080 (가로로 넓게) | 세로 사진은 위아래가 잘립니다 |
| 시공사례 | 1200×900 (4:3) | |

한 장에 **10MB** 까지입니다. 요즘 폰 사진은 보통 3~8MB라 대개 그냥 올라갑니다.

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| `/admin` 이 "아직 연결 전입니다" | 서버를 다시 시작하지 않았습니다. `Ctrl+C` 후 `npm run dev` |
| 로그인이 "이메일 또는 비밀번호가 올바르지 않습니다" | 4단계에서 **Auto Confirm User** 를 안 켰을 가능성. Users 목록에서 해당 계정의 확인 상태를 보세요 |
| 로그인은 되는데 "관리 권한이 없습니다" | **`supabase/make-admin.sql` 을 SQL Editor 에 붙여넣고 실행하세요.** 2단계 SQL 보다 계정을 먼저 만들었거나, 두 번째 이후 계정인 경우입니다 |
| 사진 업로드가 "업로드 실패" | 권한 정책 문제입니다. 2단계 SQL 을 다시 실행하세요 |
| 갑자기 전부 안 됨 | 무료 플랜은 일주일 미사용 시 자동 정지됩니다. 대시보드에서 **Restore project** |
| 뭐가 문제인지 모르겠음 | `npm run supabase:check` |

## 알아두실 것

**연결해도 기존 방식은 그대로 씁니다.** `public/images/` 에 파일명 맞춰 넣는 방법과
관리자 화면 업로드를 섞어 쓸 수 있습니다. 기존 사진을 지울 필요 없습니다.

**Supabase 가 멈춰도 홈페이지는 살아 있습니다.** DB 를 못 읽으면 코드에 들어 있는
기본 내용으로 자동 대체됩니다. 회사 홈페이지가 빈 화면이 되는 일은 없습니다.

**삭제는 되돌릴 수 없습니다.** 확실하지 않으면 "홈페이지에 보이기" 체크를 풀어
숨기는 쪽을 쓰세요.

**무료 플랜 한도**: 저장공간 1GB, 파일 5GB. 사진 한 장 2MB 기준 수백 장은 들어갑니다.
