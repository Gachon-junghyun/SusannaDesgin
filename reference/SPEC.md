## 1. 견적문의 폼 — 실측 필드 구조

### 레퍼런스 3종 비교 (실제 DOM에서 추출)

**A. 홍간판** — 히어로 인라인 초간단형 (`action=/board/contact/write`)

| 필드 | 타입 |
|---|---|
| 이름 | text |
| 연락처(숫자만 입력) | text |
| 설치지역(ex. 수원) | text |
| 설치할 층수(ex. 2층) | text |
| (필수) 개인정보 제3자 제공 동의 | checkbox |

→ 버튼 `상담 신청`. **4필드**. 이메일조차 안 받음 — 전화 회신 전제.
→ `설치할 층수`가 핵심 인사이트: 간판업은 **층수 = 고소작업차 필요 여부 = 견적 변수**.

**B. 비스퀘어** — 전체 견적폼 ★ 우리 기준안

| 필드 | 타입 | 필수 |
|---|---|---|
| 상호/담당자명 | text | ● |
| 연락처 | text | ● |
| Email address | email | ● |
| 우편번호 + `우편번호 찾기` 버튼 | text + button | ● |
| 주소 / 상세주소 | text ×2 | ● |
| **간판유형** | radio: 채널간판·플렉스간판·돌출간판·내부간판·기타 | |
| 문의내용 | textarea | |
| 첨부파일 (최대 5개) | file | |
| 개인정보 수집 및 이용 동의 | checkbox + **약관 전문 스크롤박스** | ● |

→ 버튼 `문의하기`. 폼 우측 상단에 **전화번호·이메일·주소 병기**. 우측 하단 **카카오 `톡상담` 플로팅**.

**C. 삼익THK** — 대기업형 (참고만)
- 문의자 구분 radio (협력업체/고객/기타) → 유형별 폼 분기
- 전화번호를 `select(앞자리) + text + text` 3분할
- **자동입력방지(캡차) 필드** + 새로고침 버튼
- 첨부파일 + 개인정보 동의

### → 수산나디자인 폼 확정안

**히어로 인라인 (3필드, 전환용)**
```
성함*        text
연락처*      tel      → 숫자만, 자동 하이픈
설치지역*    text     placeholder="예: 수원시 팔달구"
[ ] (필수) 개인정보 수집·이용 동의   → 전문 펼치기
                                    [ 무료 견적 신청 ]
```

**견적문의 페이지 (전체폼)**
```
상호/담당자명*   text
연락처*          tel
이메일           email      ← 비스퀘어는 필수지만 이탈 유발, 선택 권장
설치주소*        우편번호 찾기(다음 우편번호 API) + 주소 + 상세주소
설치 층수*       select  1층 / 2층 / 3층 / 4층 이상 / 옥상   ← 홍간판 인사이트
간판유형*        radio   채널간판 / 스카시(플렉스) / 돌출간판 / 내부사인 / LED전광판 / 기타
예상 시공시기    select  1주 이내 / 1개월 이내 / 미정
문의내용         textarea
첨부파일         file    현장사진·로고파일, 최대 5개 / 10MB
개인정보 동의*   checkbox + 전문 스크롤박스
                                        [ 견적 문의하기 ]
```

**검증 규칙**
- 연락처: `^01[016789]-?\d{3,4}-?\d{4}$` 또는 지역번호 허용
- 필수 미입력 시 해당 필드 하단 인라인 에러 (alert 금지)
- 제출 중 버튼 disabled + 스피너, 성공 시 완료 화면 전환
- 스팸 방지: honeypot 필드 + 제출 rate limit (캡차는 전환 깎으므로 후순위)

## 2. 개인정보 처리 — 법적 필수

개인정보보호법 제15조. 동의 체크박스만으로는 부족하고 **아래 3가지를 폼 안에서 고지**해야 함 (비스퀘어는 스크롤박스로 전문 노출).

| 항목 | 내용 |
|---|---|
| 수집 항목 | 성명, 연락처, 이메일, 설치주소 |
| 수집 목적 | 견적 상담 및 시공 안내 |
| 보유 기간 | 상담 완료 후 O개월 / 즉시 파기 |
| 거부 권리 | "동의를 거부할 수 있으며, 거부 시 견적 상담이 제한됩니다" ← **반드시 명기** |

별도 페이지로 `/privacy` (개인정보처리방침) 필요.

- [ ] 모바일에서 전화번호 `tel:` 링크 (원탭 통화)
- [ ] 카카오 `톡상담` 플로팅 버튼 (비스퀘어) 또는 채팅 위젯 (시스메이트)

- [ ] 이미지 최적화 — `next/image`, WebP

## 5. 아직 필요한 정보

`config/site.ts` 한 파일에 모아 플레이스홀더로 넣고, 나중에 그 파일만 고치면 전체 반영되도록 처리 예정.

- 대표번호 / 대표자명 / 사업자등록번호 / 주소 / 이메일
- 옥외광고사업자 등록번호 (있으면)
- 카카오톡 채널 ID (톡상담 버튼용)
- 영문 표기 — `SUSANNA DESIGN` 으로 가정
